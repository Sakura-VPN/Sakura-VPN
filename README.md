# Sakura VPN

Удобный и быстрый VPN для Google Chrome.

## 📦 Установка
Шаг 1. Скачайте и распакуйте .zip архив.
Шаг 2. Зайдите на chrome://extensions.
Шаг 3. Включите "Режим разработчика"
Шаг 4. Нажмите "Загрузить распакованное расширение"
Шаг 5. В папке с расширением, выберете папку с версией (например, 1.0.0)
Готово! Можно пользоваться!

## ⚠️ Примечание
Sakura VPN является форком Qu VPN. Оригинальный проект послужил основой для разработки, однако Sakura VPN содержит собственные изменения и доработки.
